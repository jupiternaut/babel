# ADR-003：确定 Nimbalyst 底座，新增 Google Tasks 与 SSH 设备后台

日期：2026-09-14。状态：产品方向已由用户明确指定；实现及部署尚未完成。

## 决策

1. Nimbalyst 是主产品底座。Vibe Kanban、Cline、Hermes、Cursor 示例提供可复用模块和设计参考，不再作为替换主底座的候选。
2. 展示 TODO → RUNNING → DONE → ARCHIVED，task_id 不变；归档保留原结果，运行与重试记录单独持久化。
3. 独立 Babel 常驻后台为 Nimbalyst 提供共享任务、Google Tasks 导入、设备状态与执行控制；不将官方独立商业协作服务器视为 MIT 开源组件。
4. Google Tasks 通过用户 OAuth 和 API 定时导入。当前 API 未提供任务变更原生 Webhook，首版按 60 秒轮询设计；自动导入不等于自动启动。
5. Ubuntu 后台每 60 秒用 SSH 收集登记设备的快照。Agent adapter/节点保存执行事件；后台统一分发给客户端。关闭 Nimbalyst 不应停止后台采集或远端任务。

## 取代与保留

取代 [ADR-002](ADR-002.md) 中“主前台未定，先评估 Cline 作为基础”的提案。保留桌面式起始页视觉、Babel 单一任务源，以及文件访问、权限、幂等、失联/取消确认和 PDF/Ops 要求。恢复 Nimbalyst 作为主宿主不恢复 ADR-001 的 Deck 任务权威或 Nextcloud 身份假设。

完整状态规则、同步冲突、SSH 能力边界、源码复用与验收见 [Nimbalyst 系统规格](../NIMBALYST-SYSTEM-SPEC.md)。旧机器契约和任务需一致迁移；本记录不代表可直接按旧任务清单实施。
